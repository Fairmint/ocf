# `ocf_version` 1.2.0 (positive)

Manifest declares `1.2.0` with no extension fields on `base/`.

**Schema bundle used:** this reference validator still validates file payloads with the **in-repo**
OCF schema tree (currently 1.3). It does **not** download the published 1.2 schema release. See
`utils/ocf-version.mjs` (`resolveOcfSchemaBundle`) and OCIP-0001 §2.2.
